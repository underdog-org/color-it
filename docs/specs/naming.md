# 產品名稱決策記錄

> 狀態：2026-08-03 拍板 **Colorlull**（原名 `Color It`）
> 對應 `prd.md` A1、`roadmap/M0.md`、`roadmap/checkpoints.md`

## 為什麼不能叫 Color It

| 證據 | 內容 |
|---|---|
| USPTO | **COLORIT**，序號 86770128、**註冊號 5152095**，狀態 `700 - Registered`（活體），**Class 016**（著色本、素描本、著色用筆），Pseudo Mark 欄位明載 "COLOR IT"，持有人 PROFOUND COLOR, LLC |
| 網域 | `colorit.com` 為該公司**營業中**的成人著色本／畫材電商（Shopify） |
| App Store | `Color it - by Global Colors` 已在架 |

Class 16 與 Class 9 雖不同類，但商品同屬「著色」領域，likelihood of confusion 的風險偏高。
**這不是遠親撞名。** 此時改名代價為零，排到 S2b 才發現要連帶重做 Logo、品牌基礎與商店截圖版型。

## 其他候選為何落選

| 名稱 | 落選原因 |
|---|---|
| Coloree | iOS 已有完全同名 `Coloree – Color Analysis`（iFamilySC）；該公司 2026-01-23 提出序號 99611587 的 **Class 9** 申請，審查中 |
| Colory | App Store 已有同類別的 `Colory - Coloring Book`；商標本身乾淨（序號 88304671 已 Abandoned） |
| Colorie | 法律面最乾淨（USPTO 零筆），但 App Store 搜 "colorie" 回傳 24 筆**全是卡路里 App**，且 Google Play 已有 `Colorie - Coloring Book` |

三者拼寫只差一個字母、對母語者近乎同音——這個音節空間已經飽和，本身就是該換方向的訊號。

## Colorlull 的查證結果

| 項目 | 結果 |
|---|---|
| USPTO | 🟢 全庫 0 筆 |
| App Store | 🟢 0 筆同名 |
| `.com` | 🟢 whois 回 `No match for domain "COLORLULL.COM"` |
| ASO | 🟢 保留 `color` 詞根有利關鍵字比對，且獨特到可完全佔有搜尋結果 |
| 語意 | color + lull（使平靜）。正中「安靜、專注、無社群」的定位 |

已知風險：名詞 "a lull" 有「停滯／空檔」的次要義，但在 `color +` 複合下讀者會取動詞義。

## 尚未查證 — 上架前必須補

以上是公開資料庫的初步盡職調查，**不是法律意見**。以下項目本次查不到：

- [ ] **`.app` 網域是否真的可註冊**——僅確認「無 NS 記錄」，這不等於未註冊。到 registrar 搜尋框確認即可（30 秒）
- [ ] **App Store Connect 保留名稱**（免費，保留 180 天）——這是唯一能證明該字串可用的管道
