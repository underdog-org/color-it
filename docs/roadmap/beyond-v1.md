# v1 之後

> [里程碑索引](./README.md)

**以下皆未承諾，僅記錄已知方向，避免在 v1 期間被討論打斷。**

排序依據是「對留存與續訂的預期影響」，實際優先序需上線後依真實數據重排。

### 第一優先｜Android（原 E4 ＋ I2）

移出 v1 的理由：單人配置下，Compose 版四條路由 ＋ Play Billing ＋ Auto Backup 至少 4–6 週，而 v1 的核心假設（有沒有人付錢）在 iOS 上就能驗證。

**v1 已經為它付的預付款**：

- Rust 核心跨平台，`render` crate 用 wgpu 而非 Metal
- uniffi 從 S0 就導入，Kotlin binding 是加一行設定
- D2 已驗證資產格式在 Android 可用
- `architecture.md` 的 Android 欄位全部保留為規格

**還要做的**：Android `engine-bridge`、Compose Shell、Play Billing、Auto Backup（含 25MB 配額策略）、三檔裝置的效能基準線與最低支援規格。

### 其餘方向

| 方向 | 說明 | 預估依賴 |
|---|---|---|
| 縮時影片優化 | 若 v1 數據顯示分享率高，值得投入更多（濾鏡、配樂、比例選擇） | 無 |
| 主題色盤 | 節慶、莫蘭迪等預設調色盤。低成本、高感知價值 | 無 |
| 陰影層開關 | 讓使用者決定要不要 `T_shade` | 資產需標記 shade 是否可選 |
| iPad 專屬佈局 | 平板使用者的體驗目前是放大的手機版 | 無 |
| Apple Pencil 進階 | 雙擊切換工具、懸停預覽 | InputAdapter 擴充 |
| 更多筆刷 | **需要證據支持**——若數據顯示使用者只用兩支，加筆刷是反向操作 | 需 v1 使用數據 |
| Widget | 顯示進行中的作品 | 無 |
| 更多語言（德、西） | i18n 結構已在 v1 建立，加語言是內容工作 | 無 |

### 明確不在 v1 之後的規劃中

`prd.md §9 Don't Have` 列出的項目（社群、帳號、跨平台同步、廣告、遊戲化、AI 上色、匯入自訂線稿）**不因 v1 上線而重新開放討論**。若要推翻，需要先推翻 `prd.md §3` 的核心原則。
