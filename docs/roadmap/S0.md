*CI*

- [x] `verify-generated` 進 CI：binding 過期時失敗（Linux job；macOS 的 xcframework gate 另用 paths-filter 節流）
- [x] `apps/ios/Generated/` 進 `.gitignore`，CI 每次重建（M0 既有規則已涵蓋）
- [x] `cargo xtask lint-ios` 進 Linux job：純文字檢查 `apps/ios/ColorApp/**` 不得出現 `RustEngine`、不得 `import colorlull_engine`

> **三條驗收待人工確認。** 它們需要在模擬器上實際點擊，而自動化這件事要嘛加 XCUITest target
