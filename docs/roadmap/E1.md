# E1｜手感垂直切片（W5–10）★ 最高風險

> 上一個：[S0](./S0.md)｜下一個：[E2](./E2.md)｜[里程碑索引](./README.md)


**只做一支軟圓筆 ＋ 油漆桶。不做抽象、不做 UI 打磨。**

| | |
|---|---|
| **範圍** | Rust ＋ wgpu 起手、composite、`T_wet`、三個 pass、油漆桶 ＋ 擴散動畫 |
| **前置依賴** | M1 產出至少一個 `.colorpack`、S0 |

**產出物**

- `core/render`、`core/stroke`、`core/colorpack` 的可運作版本
- iOS 端 `MTKView` ＋ `CADisplayLink` ＋ `InputAdapter`
  - 含 `predictedTouches`
  - **含 `majorRadius` → `pressure` 的自適應正規化**
- One-Euro filter ＋ Catmull-Rom 插值
- **Mask Mode A / B 兩種都實作，可即時切換比較**
- **`docs/perf-baseline.md` 第一版**

**實作清單**

*wgpu 起手*

- [x] `core/render`：wgpu instance / adapter / device / queue 初始化，**唯一 import wgpu 的 crate**
- [ ] iOS `CAMetalLayer` → `RawSurfaceHandle` 傳入 `Engine::new`；**GPU resource 絕不跨界**（Boundary 1 紅線 1）
- [x] `core/colorpack`：讀 `.colorpack`、`regions.bin` RLE 解碼 → `T_region`（**R16Uint、NEAREST、只能無損**）
- [x] 文件級 GPU 資源配置：`T_line` / `T_shade` / `T_region` / `T_paint` / `T_erase` / `T_wet` / `Buf_palette`
  - 無 `shade` 的文件綁 1×1 白色 dummy texture，**不做 shader variant**

*composite pass*

- [x] WGSL composite shader 六層：`palette×erase` → `paint` → `wet` → `shade` → `line`（`architecture.md §4.2 Pass 3`）
- [x] `PAPER_WHITE` 常數——未上色 = 白紙而非透明
- [x] `set_viewport`：畫布 transform ＋ full-screen triangle

*stroke 管線*

- [x] `core/stroke`：`generate_dabs(samples, preset, size, seed)` 純函式——**純資料進出、零 GPU 依賴**（Boundary 2）
- [x] One-Euro filter → 向心 Catmull-Rom 插值 → 依 `spacing` 取樣 → `Dab`
- [ ] **Pass 1 Stroke**：instanced quad × dab_count → `T_wet`，scissor 至 stroke bbox；`build_up` 切 blend mode
- [ ] **Pass 2 Commit**（僅一般筆刷路徑 (a)）：`tint × opacity × mask` → `T_paint`，收尾清 `T_wet`

*油漆桶*

- [ ] `tap(x, y)` → `T_region` 取 ID → `Buf_palette[id] = color`（**O(1)，不做泛洪填充**）
- [ ] `Fill` 順帶清該區域的 `T_erase`（scissor 至 region bbox，以 `T_region` 為 mask）
- [ ] 擴散動畫：composite shader 內 `smoothstep`；`fill_origin` / `max_radius` 為 **per-tap** 而非 per-region（shader 側；CPU 推進歸 `E1-bucket`）

*輸入*

- [ ] iOS `MTKView` ＋ `CADisplayLink`——**渲染由 FrameDriver 驅動，不由輸入事件驅動**
- [ ] `InputAdapter`：`coalescedTouches` ＋ `predictedTouches`；預測點標記 `predicted: true`，**不進 oplog**
- [ ] `majorRadius` → `pressure` 的**自適應**正規化（per-stroke running baseline，不得用固定 min/max）
- [ ] `cancel_stroke`：palm rejection 事後判定失敗時直接清 `T_wet`，`T_paint` 從未被污染

*Mask Mode*

- [ ] Mode A（嚴格，`id == active_region_id`）與 Mode B（**寬鬆＝無條件通過**；`REGION_LINEART` 不存在，見 `E1-composite.md §6`）兩種都實作，**可在真機上即時切換比較**（D4 的輸入）

*量測與調校*

- [ ] motion-to-photon 量測方法：240fps 以上高速攝影的**流程文件化**（不只量一次，要能重複量）
- [ ] `docs/perf-baseline.md` 第一版：測試裝置清單（iOS 高階與中階各一台）＋ 各指標實測值
- [ ] 記憶體峰值量測：1:1 最大畫布 ＋ 連續塗抹 30 秒 ＋ undo pool 塞滿，對照 `architecture.md §4.1.1` 的 145MB 預算
- [ ] 油漆桶擴散動畫時長實機調校（初始值 180ms ease-out）
- [ ] One-Euro filter 與 `majorRadius` 正規化參數實機調校
- [ ] **細長區域的圓形擴散「追趕感」實機評估**——決定是否值得改測地距離擴散（`architecture.md §4.5`）
