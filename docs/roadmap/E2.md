**實作清單**

*五支筆刷*

- [ ] 四張 tip 貼圖：軟圓、硬圓、顆粒紋理、大軟圓
- [ ] 五個 `BrushPreset` 常數（含 `edge_boost` 欄位，非水彩皆為 0）
- [ ] 麥克筆（硬圓 ＋ Multiply）與蠟筆（顆粒紋理 ＋ Normal）
- [ ] 噴槍（`build_up = true`，同筆內 over 累積）
- [ ] **水彩的 commit 內 unsharp**：`edge = max(w - box3x3(w), 0)`、`a = saturate(w × (1 + edge × edge_boost))`，blur 半徑隨 brush size 縮放（`architecture.md §4.2 (d)`）
  - **時間盒 3 天。** 超過仍做不出辨識度，直接走 `architecture.md §14 R7` 的第三段退路（砍成四支）

*Multiply 與 `T_erase`*

- [ ] **Pass 2 (b) bbox ping-pong**：`T_bg = over(palette × (1 - T_erase), T_paint)`，讓 Multiply 對油漆桶底色生效
- [ ] `T_erase`（R8）貼圖配置 ＋ 記憶體預算複核（+4MB，見 `architecture.md §4.1.2`）
- [ ] **Pass 2 (c) 橡皮擦 MRT 雙寫**：target 0 = `T_paint` destination-out、target 1 = `T_erase` additive
- [ ] 橡皮擦**固定 Mode B、不提供模式選擇**；`Op::Fill` 清該區 `T_erase`（E1 已做，此處補測試）

*Mask Mode 參數化*

- [ ] 筆刷大小隨 zoom 的行為定義（畫布空間固定 vs 螢幕空間固定，**擇一並寫進 `architecture.md`**）

**驗收標準**

- [ ] **五支筆刷的差異一眼可辨**（盲測：受試者能在不看名稱的情況下區分）

- [ ] 橡皮擦能擦掉油漆桶填色，且擦後再填色不留殘影（`Op::Fill` 清 `T_erase`）
- [ ] golden test 在 CI 綠燈，且刻意改動 preset 參數時會失敗
- [ ] 縮放至最大倍率時筆刷邊緣無明顯鋸齒
- [ ] 效能與記憶體基準線未較 E1 回歸（`T_erase` 已計入預算）
- [ ] **水彩的結論已明確記錄**——保留（附 `edge_boost` 定值）或砍成四支，兩者皆可，但不得懸而未決帶入 S1
