# SL｜Soft Launch（W28–30）

> 上一個：[S2](./S2.md)｜下一個：[S3](./S3.md)｜[里程碑索引](./README.md)


**只有一個目的：在投入剩餘 8 週之前，驗證「有沒有人願意付錢」。**

| | |
|---|---|
| **範圍** | 單一市場、5–8 張圖、零行銷預算、完整付費流程 |
| **前置依賴** | S2 |

**產出物**

- 精簡版上架素材（截圖、描述、隱私標籤、分級）
- 單一市場上架（建議選英語系小市場，避免污染主市場的初期評分）
- 分析事件埋點：下載 → 首次開啟線稿 → 完成一張 → 進入付費牆 → 試用 → 轉換

**實作清單**

*上架素材*

- [ ] 精簡版商店素材：截圖（用 S2 的版型與實際完成稿）、描述、隱私標籤、**年齡分級 4+**
- [ ] 商店分類設為 **Lifestyle / Entertainment**——**不進 Kids Category**（`prd.md §2`）
- [ ] 選定 soft launch 市場（`prd.md` A7，建議英語系小市場）

*分析埋點*

- [ ] 匿名事件埋點：下載 → 首次開啟線稿 → 完成一張 → 進入付費牆 → 試用 → 轉換
- [ ] 確認事件**不含任何可識別個人的資訊**

*送審*

- [ ] 首次送審——**同時把整條送審流程走過一遍當作預演**
- [ ] 使用者回饋收集管道（手感與內容兩類分開收）

**驗收標準**

- [ ] 送審通過（**同時完成整條送審流程的預演**，正式上架時不會有意外）
- [ ] 取得完整漏斗數據，觀察期至少 3 週
- [ ] 取得第一批真實使用者的手感與內容回饋

> Soft launch 的觀察期（W30 起）與 S3 並行——觀察數據不需要全職投入。
