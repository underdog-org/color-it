# S3｜雲端與備份（W31–34）

> 上一個：[SL](./SL.md)｜下一個：[R1](./R1.md)｜[里程碑索引](./README.md)


| | |
|---|---|
| **範圍** | R2 資產目錄、Cloudflare Worker 解鎖、iCloud Drive 備份、手動匯出/匯入 |
| **前置依賴** | S2 |

**產出物**

- R2 bucket ＋ 版本化圖庫目錄 JSON（ETag 快取）
- Cloudflare Worker：收據驗證 → presigned URL
- **iCloud Drive ubiquity container 備份與還原**（已拍板，見 `architecture.md §11.3`）
- 手動匯出 / 匯入作品檔（**v1 Must Have**）
- `asset_hash` 失效時的唯讀降級處理（PRD P1-b）

**實作清單**

*R2 ＋ Worker*

- [ ] R2 bucket ＋ **版本化圖庫目錄 JSON**——免費/付費切分放這份（可變），**不放進 `.colorpack`**（不可變）
- [ ] client 端 ETag 快取
- [ ] Cloudflare Worker：收據驗證 → R2 presigned URL（15 分鐘有效，無資料庫無 session）
- [ ] 免費圖包 bundle 進 App 或走公開 R2

*iCloud Drive 備份*

- [ ] iCloud container 設定 ＋ ubiquity container 目錄結構（**文件放子資料夾**以降低誤刪風險）
- [ ] **`NSFileCoordinator` 包住所有讀寫**，與 `architecture.md §8.3` 的 atomic rename 一起設計
- [ ] **`NSMetadataQuery` 監聽下載狀態 ＋ `startDownloadingUbiquitousItem`**——換機還原時檔案是 placeholder，不能假設 `FileManager` 讀得到內容
- [ ] **`NSFileVersion` 衝突解析**：保留最後修改者，**衝突版本另存不刪除**（P1）
- [ ] 未登入 iCloud 的降級：設定頁備份區塊顯示「未啟用」並引導至手動匯出——**不彈窗、不阻斷**
- [ ] 配額接近上限的降級（E3 已實作策略，此處接上實際配額查詢）

*手動匯出 / 匯入*

- [ ] 匯出作品檔到系統「檔案」App（**因檔案已在 ubiquity container，此處主要是加分享面板入口**）
- [ ] 匯入還原：讀取外部檔案 → 驗證 schema 版本 → 建立文件
- [ ] 設定頁的「備份」區塊：說明備份範圍與限制（**不在 onboarding 提**）

*`asset_hash` 降級*

- [ ] `asset_hash` 失效時以唯讀模式開啟並顯示縮圖——**絕不刪除文件、絕不套用錯誤資產**

**驗收標準**

- [ ] 未訂閱狀態下無法直接取得付費 pack 的 URL
- [ ] iOS 換機還原：作品清單與 palette 完整還原
- [ ] 備份總量接近配額上限時的行為符合設計（不得靜默失敗）
- [ ] 手動匯出的檔案能在另一台裝置匯入並正確開啟
- [ ] 刻意提供不存在的 `asset_hash`：作品以唯讀模式開啟，**不被刪除、不套用錯誤資產**
