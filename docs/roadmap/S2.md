# S2｜Share ＋ Subscription（W25–27）

> 上一個：[E3](./E3.md)｜下一個：[S2b](./S2b.md)｜[里程碑索引](./README.md)


**IAP 的外部行政流程必須在 W20 就啟動，理由見 [checkpoints.md](./checkpoints.md) 外部前置。**

| | |
|---|---|
| **範圍** | Share 畫面、靜圖與縮時匯出、付費牆、StoreKit 2、**解鎖 Worker**、完成建議與完成動畫 |
| **前置依賴** | S1、E3；App Store Connect 帳務設定（外部） |

**產出物**

- Share 畫面 ＋ 系統分享面板整合
- **匯出 composition 層**：畫布置中 ＋ 背景延伸，letterbox 到 1:1 / 4:5 / 9:16
- 付費牆 UI ＋ 三個進入點
- 訂閱購買、還原購買、狀態查詢
- **訂閱到期後的行為驗證**（PRD P1-a）
- **Cloudflare Worker：收據驗證 → R2 presigned URL**（原排在 S3，前移）
- **完成建議 ＋ 完成動畫**（`prd.md §9` Must Have）

**實作清單**

*Share*

- [ ] Share 畫面 ＋ 系統分享面板整合（**不做站內社群**）
- [ ] 靜態圖片匯出：**白底** PNG，含線稿與 shade 合成
- [ ] 「已分享」狀態回寫——它是 Gallery 卡片第三個進度維度的**唯一**來源（客觀事實，非推測）

*匯出 composition*

- [ ] 匯出 composition 層：畫布置中 ＋ 背景延伸填滿目標比例
- [ ] 三個目標比例：1:1（通用）/ 4:5（IG 直式）/ **9:16**（Stories、Reels、TikTok、Shorts）

*付費牆*

- [ ] 付費牆 UI：月訂閱 ＋ 年訂閱（年費折扣約 40%）＋ 年訂閱 7 天試用
- [ ] 三個進入點：點擊鎖定線稿、Gallery 訂閱入口、**已分享第 N 張之後**——第三個進入點以「**已分享** N 張」為準，不是「觸發完成建議 N 次」（`prd.md §5.1` 的 Gallery 第三維度用的就是「已分享」，且它更保守、較不會打擾；**N 值待上線後校準**，`prd.md` A5）
  - 定義見 `prd.md §5.4`（N 值仍待上線後校準，附錄 A5）
- [ ] **不打擾規則落實**：編輯過程中不彈付費牆、評分請求、推播授權；不做倒數計時與假的限時優惠

*StoreKit 2*

- [ ] 訂閱購買、還原購買、狀態查詢
- [ ] **訂閱到期後的行為**：僅「開啟新的付費線稿」被鎖，既有作品完全不受影響（P1-a）
- [ ] 沙盒測試環境設定與帳號準備（D6 的前提）
- [ ] 各地區價格層級設定（`prd.md` A2）——soft launch 市場先設，R1 補齊全市場

*解鎖 Worker*

> 這一塊原排在 S3，前移是因為 **SL 要驗證的就是「訂閱 → 解鎖 → 下載」這條鏈路**，排在 SL 之後等於 D7 量不到東西。

- [ ] **Cloudflare Worker：收據驗證 → R2 presigned URL**（15 分鐘有效，**無資料庫、無 session**）
- [ ] 付費 pack 的下載串接：付費牆購買成功 → 取得 URL → 走 S1 的下載器

*完成建議與完成動畫*

- [ ] 完成建議的呈現：文案「看起來不錯了，要分享嗎？」——**是建議不是判定**（`prd.md §5.2`）
- [ ] 完成動畫（`prd.md §9` Must Have，付費牆第三個進入點依賴它）
- [ ] 「不打擾」規則下的出現時機：**不在編輯過程中打斷**（觸發條件的判定邏輯已在 E3）

**驗收標準**

- [ ] **沙盒環境完成一次完整購買 ＋ 還原**
- [ ] 訂閱到期模擬：既有作品仍可開啟、編輯、匯出；僅新的付費線稿被鎖
- [ ] 已開始編輯的付費線稿，在探索分頁**不顯示鎖頭**
- [ ] 編輯過程中確認不會彈出任何打斷（付費牆、評分、推播授權）
- [ ] 縮時影片 letterbox 到 9:16 後在 Instagram / TikTok 實際上傳測試
- [ ] 「已分享」回寫後 Gallery 卡片正確更新
- [ ] 未訂閱狀態下無法直接取得付費 pack 的 URL；購買成功後「取得 URL → 下載 → 開啟付費線稿」全鏈路走通
- [ ] 完成建議只在全區已上色且距上一筆 > 3 秒時出現，編輯過程中不打斷
- [ ] **刻意留白的作品不觸發完成動畫**（`prd.md §10` T2 的反向驗證——這是已接受的取捨，不是 bug）
- [ ] 本里程碑期間改變的決策已寫回 `prd.md` / `architecture.md` / `roadmap/`，沒有只存在於腦中的決定
