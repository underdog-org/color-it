# S2｜Share ＋ Subscription（W25–27）

> 上一個：[E3](./E3.md)｜下一個：[SL](./SL.md)｜[里程碑索引](./README.md)


**IAP 的外部行政流程必須在 W20 就啟動，理由見 [checkpoints.md](./checkpoints.md) 外部前置。**

| | |
|---|---|
| **範圍** | Share 畫面、靜圖與縮時匯出、付費牆、StoreKit 2、**品牌與 Logo** |
| **前置依賴** | S1、E3；App Store Connect 帳務設定（外部） |

**產出物**

- Share 畫面 ＋ 系統分享面板整合
- **匯出 composition 層**：畫布置中 ＋ 背景延伸，letterbox 到 1:1 / 4:5 / 9:16
- 付費牆 UI ＋ 三個進入點
- 訂閱購買、還原購買、狀態查詢
- **訂閱到期後的行為驗證**（PRD P1-a）
- **App Logo / App Icon ＋ 品牌基礎**（原排在 R1，提前，理由見下）

> **★ 品牌為什麼從 R1 提前到這裡**：SL（W28–30）要真的上架，而 **D7 量的是付費轉換率**。商店頁的第一印象直接影響那個數字——用臨時 Logo 測出來的轉換率，不足以支撐「是否繼續投入剩餘 8 週」這個決策。
>
> 若 SL 用臨時素材，D7 的低轉換率會有兩種無法區分的解釋（產品不吸引人 vs 商店頁太隨便），而 D7 的整個價值就在於區分它們。

**實作清單**

*Share*

- [ ] Share 畫面 ＋ 系統分享面板整合（**不做站內社群**）
- [ ] 靜態圖片匯出：**白底** PNG，含線稿與 shade 合成
- [ ] 「已分享」狀態回寫——它是 Gallery 卡片第三個進度維度的**唯一**來源（客觀事實，非推測）

*匯出 composition*

- [ ] 匯出 composition 層：畫布置中 ＋ 背景延伸填滿目標比例
- [ ] 三個目標比例：1:1（通用）/ 4:5（IG 直式）/ **9:16**（Stories、Reels、TikTok、Shorts）

*付費牆*

- [ ] 付費牆 UI：月訂閱 ＋ 年訂閱（年費折扣約 40%）＋ 年訂閱 7 天試用
- [ ] 三個進入點：點擊鎖定線稿、Gallery 訂閱入口、完成第 N 張之後（**N 值待上線後校準**，`prd.md` A5）
- [ ] **不打擾規則落實**：編輯過程中不彈付費牆、評分請求、推播授權；不做倒數計時與假的限時優惠

*StoreKit 2*

- [ ] 訂閱購買、還原購買、狀態查詢
- [ ] **訂閱到期後的行為**：僅「開啟新的付費線稿」被鎖，既有作品完全不受影響（P1-a）
- [ ] 沙盒測試環境設定與帳號準備（D6 的前提）

*品牌與 Logo*

- [ ] **App Logo 與 App Icon**
- [ ] 品牌基礎：主色、字體、名稱確認——**含 `Color It` 的商標與 App Store 名稱可用性檢查**（`prd.md` A1）
- [ ] SL 用的商店截圖版型——**截圖內容必須是實際完成稿，不是 UI 截圖**（`prd.md §1`）

**驗收標準**

- [ ] **沙盒環境完成一次完整購買 ＋ 還原**
- [ ] 訂閱到期模擬：既有作品仍可開啟、編輯、匯出；僅新的付費線稿被鎖
- [ ] 已開始編輯的付費線稿，在探索分頁**不顯示鎖頭**
- [ ] 編輯過程中確認不會彈出任何打斷（付費牆、評分、推播授權）
- [ ] 縮時影片 letterbox 到 9:16 後在 Instagram / TikTok 實際上傳測試
- [ ] **App Store 名稱可用性確認完成**——若 `Color It` 不可用，此時改名的代價遠低於 SL 之後
