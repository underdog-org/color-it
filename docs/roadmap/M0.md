# M0｜專案基建與交付規格（W0–1）

> 下一個：[M1](./M1.md)｜[里程碑索引](./README.md)


**最先啟動。** 這裡的三塊工作都是「做完就不會再回頭」的一次性投入。

| | |
|---|---|
| **範圍** | cargo workspace、CI、繪師交付規格文件、三張試作素材的來源檔 |
| **前置依賴** | 無 |

**產出物**

- cargo workspace 骨架（`core/*`、`tools/baker`、`xtask`、`contracts/`）
- GitHub Actions CI（`architecture.md §12.3` 觸發矩陣的 v1 子集）
- **繪師交付規格文件** → `docs/specs/assets-spec.md`（四個 PNG ＋ `meta.json` 的硬性要求、解析度、比例、色彩空間、CSP 操作、交付前自檢清單）
  - **必須寫成「給外人看的」**——M0 期間素材由工程自製，但這份文件真正的讀者是未來的外包繪師
- 三張試作素材的來源檔於 `assets/source/`：
  - **兩張手繪真作品**（1:1 與 4:5 各一，其中一張帶 `shade`）——同時是 E1 的輸入與未來給繪師的風格基準
  - **一張程式生成的 torture test**（細碎區域、單像素縫隙、面積 < 200px 的碎片）

**實作清單**

*基建*

- [ ] cargo workspace 初始化：`core/{colorpack,stroke,render,document,history,oplog,app-state,engine}`、`tools/baker`、`xtask` 的空 crate
- [ ] 依賴方向 lint：`core/` 各 crate 的 `Cargo.toml` 依賴符合 `architecture.md §5.1` 的單向圖
- [ ] **Boundary 3 的 CI lint**：禁止 `render` 以外的 crate 在 `Cargo.toml` 列入 wgpu
- [ ] Git LFS 設定，`assets/source/**` 納入追蹤；`assets/packs/**` 進 `.gitignore`
- [ ] GitHub Actions：`core/**`、`tools/baker/**`、`contracts/**` 三條觸發路徑
- [ ] `xtask` 骨架 ＋ `cargo xtask bake` 指令位（實作在 M1）

*交付規格*

- [x] `docs/specs/assets-spec.md` 定稿：四個 PNG ＋ `meta.json` 的硬性要求、母帶長邊 4096、兩種比例、**sRGB 色彩空間**、CSP 操作步驟（「囲って塗る」／「自動選択 隙間閉じ」）、交付前自檢清單（2026-08-03 完成）
- [ ] 規格文件中對「原始分層檔不進 repo、區域切分日後調整的返工成本落在繪師身上」的說明（`architecture.md §9.1`，**必須在合作前講明**）
- [~] 繪師徵才 JD ＋ 評估方式，**W1 發出**（原排 W3，因 JD 依賴的 `specs/assets-spec.md` 已定稿而提前）——D1 量的是「**無來回澄清**」，JD 要先講明交付是依規格文件獨立完成
- [ ] `Color It` 商標與 App Store 名稱可用性檢查（`prd.md` A1）——此時改名代價為零，排到 S2b 才發現不可用會連帶重做 Logo、品牌基礎與商店截圖版型

*試作素材*

- [ ] 手繪真作品 A：1:1，`lineart` ＋ `flats` ＋ `reference` ＋ `meta.json`（**無 `shade`**，用來跑 `has_shade = false` 那條路徑）
- [ ] 手繪真作品 B：4:5，同上再加 **`shade`**（跑 `has_shade = true`）
- [ ] torture test 生成器：程式產出含細碎區域、單像素縫隙、面積 < 200px 碎片的 `flats` / `lineart`

**驗收標準**

- [ ] `cargo build --workspace` 綠燈，CI 在三條觸發路徑上皆會執行
- [ ] **wgpu lint 在刻意於 `stroke` crate 加入 wgpu 依賴時會失敗**
- [ ] `assets-spec.md` 交給一位未參與本專案的人閱讀，能複述出四個 PNG 各自的硬性要求（**這是 D1 的預演，不是 D1 本身**）
- [ ] 兩張手繪素材皆通過 `assets-spec.md` 的交付前自檢清單
- [ ] 素材的原始分層檔（`.clip` 等）不在 repo 內
- [ ] 本里程碑期間改變的決策已寫回 `prd.md` / `architecture.md` / `roadmap/`，沒有只存在於腦中的決定
