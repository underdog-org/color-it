*試作素材*

> **`has_shade` 兩條路徑的分配已改。** 原訂「A 無 shade、B 有 shade」，實際上兩張手繪素材都有 `shade`，
> `has_shade = false` 改由 `torture-01` 覆蓋（它本來就無 `shade`）。兩種比例仍是 1:1 ＋ 3:4 各一。

- [x] 手繪真作品 A：`kirby-demo-1`，1:1（4096²），`lineart` ＋ `flats` ＋ `reference` ＋ **`shade`** ＋ `meta.json`。68 個區域，畫布／sRGB／`reference` 幾何（0 px 越界）全部通過
- [~] 手繪真作品 B：`adventure-time-demo-1`，3:4（3072×4096），四張 PNG 齊全含 `shade`——**但 `flats.png` 不合規，待以 CSP 重做**（現版是成品插畫的色彩量化：171 色、其中 166 色總面積 < 200px，且 7 個區域跨線稿合併佔畫布 57.66%）。`reference.png` 的幾何是對的（99.95% 對齊線稿），重做時以它為準
- [x] torture test 生成器：`cargo xtask gen-torture`（`xtask/src/torture.rs`），12 個壓力區塊、13558 個 4-連通區域、10389 個 < 200px 碎片，單像素縫隙的對照組（不連通）與 5 組缺口（連通）皆驗證通過，重跑逐位元決定性

> **兩張手繪素材都是第三方 IP 的暫代品**（Kirby / Adventure Time），僅供 M0–E1 內部驗證，
> 不得上線，**也不能作為未來給繪師的風格基準**——那份基準仍待真實素材補上。
