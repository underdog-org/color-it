# Color It — 開發路線圖

>
> 回答「**什麼時候做、做什麼、做完怎麼算**」。

## 前提

**所有週數都建立在以下配置上。配置改變，整份時程作廢。**

| 項目 | 假設 |
|---|---|
| 工程 | **1 人全職** |
| 繪師 | 外包，1 位，穩態產能每週 3–5 張 |
| v1 平台 | **iOS only**。Android 移出 v1，見 [beyond-v1.md](./beyond-v1.md) |
| 上架形式 | 先 soft launch（單一市場），再正式上架 |

**這個配置的直接後果**：工程是關鍵路徑（約 38 週），繪師不是（量產只需 15 週）。這與 v0.1 的假設完全相反，v0.1 的「三軌並行」在單人配置下不成立。

## 里程碑

每個里程碑一份檔案，三段結構：`產出物`（交什麼）→ `實作清單`（做什麼，每條 1–3 天）→ `驗收標準`（怎麼算完成）。

| 里程碑 | 週次 | 內容 | 檔案 |
|---|---|---|---|
| **M0** | W0–1 | 專案基建、繪師交付規格、三張試作素材 | [M0.md](./M0.md) |
| **M1** | W2–3 | baker、`.colorpack` 契約、驗證測試 | [M1.md](./M1.md) |
| **S0** | W4 | 契約定義（`EngineProtocol` ＋ `MockEngine` ＋ Xcode 專案 ＋ 設計基礎） | [S0.md](./S0.md) |
| **E1** | W5–10 | 手感垂直切片 ★ 最高風險（時間盒 8 週） | [E1.md](./E1.md) |
| **E2** | W11–14 | 完整工具集（五支筆刷、橡皮擦、縮放平移） | [E2.md](./E2.md) |
| **S1** | W15–19 | Gallery ＋ Canvas Shell | [S1.md](./S1.md) |
| **E3** | W20–24 | Undo ＋ OpLog ＋ 持久化 ＋ 進度 | [E3.md](./E3.md) |
| **S2** | W25–27 | Share ＋ Subscription ＋ **品牌與 Logo** | [S2.md](./S2.md) |
| **SL** | W28–30 | Soft Launch（觀察期至 W33，與 S3 並行） | [SL.md](./SL.md) |
| **S3** | W31–34 | 雲端與備份 | [S3.md](./S3.md) |
| **R1** | W35–38 | 正式上架 | [R1.md](./R1.md) |

※ M0 / M1 的 3 張試作由工程自製，不依賴繪師。
