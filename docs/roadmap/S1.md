**產出物**

- Gallery：探索 / 我的作品兩分頁
  - 卡片狀態：下載狀態、鎖定、進度、**已分享**
  - **鎖定規則**：一旦某 `asset_id` 有對應本機文件，該 asset 在所有 UI 上不再顯示鎖定
- Canvas：工具列、筆刷大小、色盤、Undo/Redo 按鈕、返回與分享入口
- 資產下載器 ＋ 本機快取（含**已觸碰資產永久釘選**，見 `architecture.md §8.5`）
- R2 bucket ＋ 版本化圖庫目錄 JSON（ETag 快取）——**原排在 S3，前移至此**
- i18n 結構（**英文 ＋ 繁中 ＋ 日文**）
- 前期對著 `MockEngine`，末期切換為 `RustEngine`（原 I1 併入此處）
- **v1 不做 onboarding——首次啟動直接進 Gallery**（`prd.md §8`）

**實作清單**

*設計基礎*

> 這兩條原在 S0，移到 S1 是因為它們是 S1 高保真設計稿的直接輸入。

- [ ] `DesignTokens.swift`（**v1 不做 `contracts/tokens.json`**）
- [ ] **五條路由**低保真 wireframe（Gallery / Canvas / Share / Subscription / **Settings**）

*設計稿*

- [ ] Gallery 兩分頁的高保真設計稿——**重點是卡片三個狀態維度的視覺呈現**，不是好看
- [ ] Canvas 的高保真設計稿：工具列、色盤、進行中的操作態

*Gallery*

- [ ] 探索分頁：依分類瀏覽，卡片顯示縮圖 / 難度 / 鎖定狀態
- [ ] 我的作品分頁：依最後編輯時間排序，顯示進度環
- [ ] 卡片狀態機：下載（未 / 中 / 已）× 鎖定（免費 / 已解鎖 / 鎖定）× 進度（未開始 / 進行中 / 已分享）
- [ ] **鎖定規則**：一旦某 `asset_id` 有對應本機文件，該 asset 在所有 UI 不再顯示鎖定（探索分頁改顯示「繼續」）
  - **三個不可能組合以斷言排除，不畫 UI**（`prd.md §5.1`）

*Canvas*

- [ ] 工具列：筆刷 / 橡皮擦 / 油漆桶 ＋ 筆刷大小與透明度
- [ ] 色盤：建議色（讀 `manifest.palette`）＋ 最近使用 ＋ 完整色盤入口 ＋ 吸管
- [ ] 吸管：`pick_color(x, y)` FFI ＋ Canvas 取色互動（`architecture.md §6` Boundary 1；單像素 readback，非高頻路徑）
- [ ] Undo / Redo 按鈕、返回、分享入口——**分享入口一直存在，永遠不是必經路徑**

*資產分發*

> 這一塊原排在 S3，前移是因為 S1 的下載器必須對著真實的目錄與 bucket 測試才有意義。

- [ ] R2 bucket ＋ **版本化圖庫目錄 JSON**——免費／付費切分放這份（可變），**不放進 `.colorpack`**（不可變）
- [ ] client 端 ETag 快取
- [ ] 免費圖包 bundle 進 App 或走公開 R2

*資產下載與快取*

- [ ] 資產下載器，**支援中斷續傳**
- [ ] 本機快取 ＋ LRU 淘汰（僅限「從未開啟過」的資產）
- [ ] **已觸碰資產永久釘選**；且**開啟既有文件時不檢查 entitlement**（`architecture.md §8.5`）

*i18n*

- [ ] i18n 結構（英文 ＋ 繁中 ＋ 日文），字串表與複數規則
- [ ] 日文長字串與換行的全畫面版面檢查
